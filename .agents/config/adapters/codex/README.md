# Codex Adapter

Exposes the canonical `.agents/` assets to Codex.

Mapping:
- Repository instructions → root `AGENTS.md` (points to `.agents/AGENTS.md`)
- Skills → `.agents/skills/<skill>/SKILL.md`
- MCP → `.agents/mcp/connected-workspace.json`

Keep repository-wide guidance in the canonical `.agents/AGENTS.md`.
