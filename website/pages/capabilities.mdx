## Publishing flow

The newsletter and LinkedIn skills draft content in your voice, run it through the writing-quality
skills, then publish through the MCP (Gmail / LinkedIn) or deploy static HTML via FTP.

## Runtimes

The same `.agents/` library runs across three runtimes through thin adapters:

- **Claude Code** — `/assistant:<skill>` commands.
- **GitHub Copilot** — `/assistant-<skill>` prompt files (enable `chat.promptFiles`).
- **Codex / any agent** — read `.agents/AGENTS.md` and reference a skill by path.

## Templates

Visual skills build on base templates in `.agents/templates/`: `banner-base.svg`,
`diagram-base.html`, `infographic-base.html`, and `slides-base.html` — themed with your `config.brand`
design tokens.
